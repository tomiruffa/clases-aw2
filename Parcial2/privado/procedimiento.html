Procedimiento: valor del inventario

¿Qué hace?

Recorre todos los productos de la panadería y calcula cuánto dinero representa la mercadería en stock: para cada producto multiplica precio × stock y suma todos los resultados.

Opcionalmente podés indicar un porcentaje de descuento (de 0 a 100) para ver el valor del inventario si se vendiera con esa rebaja. Si lo dejás vacío se usa 0 %.

Cada ejecución queda guardada en la base de datos como historial. Endpoint: GET /procedimientos/calcular-valor-inventario?descuento=N
